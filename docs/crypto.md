# Crypto donations

- **Crypto**: the streamer's crypto gateway on Jarchi Pay (`donate.jarchi.app`): viewers donate USDT (BEP20, TRC20) straight to the streamer's own wallet. Not active: a spinning coin (drag it to spin it), what it is, and **Request crypto gateway** (the connected Kick / Twitch channel, the terms, **I accept**, **Send**: Jarchi Pay's one-time link opens in the browser, where signing in with the channel sends the request; no account connected: **Go to Connections**). Pending and rejected (until when) say so under the button. Once approved, the page turns active by itself: the donation page's link with **Copy**, today / this week (from Saturday) / all-time totals, and the donations newest first (name or Anonymous, amount, network, time, message, transaction link; a private message is marked "only for you, not read on stream"; **Replay** plays its alert again). **Pop out** opens the list alone in a small window (its pin keeps it on top). Until a wallet address is set (BEP20, TRC20 or both; one is enough), a step opens Jarchi Pay's one-time wallet link (addresses are never set in Jarchi); a wallet change waiting its 24 hours shows with **Cancel this change**. **About** shows this install's id with **Copy**.
- **Crypto alerts**: while the gateway is active, Jarchi asks Jarchi Pay for new donations every few seconds and plays each one in the same alert queue and OBS alerts link as every other alert (never two at once). The cursor is kept in `data/pay.json`, so a restart never plays one twice; one paid over 10 minutes ago (Jarchi was closed) is skipped. A hidden name shows as Anonymous, a private message is never shown on stream. **Alert settings** tab: **Coin and card**, **Cipher hologram** (default) or **Your own alert**; the two designs' sound (theirs or an upload) and duration; **Test in OBS**; optional amount alerts (the highest one a donation reaches plays). Your own alert and each amount alert open one editor with a live preview: image or GIF, sound, text position (above / below / beside), font, duration, **Play preview**, **Test in OBS**, an amount alert's minimum USDT.
