# Platform logos

Official logos, unmodified (same shape and colors). Used as the small platform icon on chat messages.

- `twitch.svg`: the Twitch "Glitch" in Twitch Purple, `glitch_flat_purple.svg` from Twitch's official brand pack (https://brand.twitch.com, `Twitch-Brand.zip`).
- `kick.svg`: the Kick "K" logo, `https://static.kick.com/kick-logo-k.svg`, the file Kick's own website uses. Kick has no public brand/press page.

To use other official files, replace these two files with the same names (SVG or PNG renamed to `.svg` won't work; keep the format: an SVG named `kick.svg` / `twitch.svg`).

These logos are trademarks of their owners and are only used to show which platform a message came from.
