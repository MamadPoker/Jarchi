# OG hats

The chat widget's hat for Kick viewers with the OG badge (**More options → Show / hide → OG hat**): a black hat with
"MP" on it, in three styles (`cap.svg`, `beanie.svg`, `fedora.svg`). Made for Jarchi; the files are used exactly as given.

The widget shows them as image files, not inline SVG: they reuse the same gradient ids (`gCrown`, `gBrim`...), which
would clash if several were in one page.
